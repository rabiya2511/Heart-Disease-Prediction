# Heart Disease Detecion using Machine Learning
An  Intelligent machine learning system to predict the presence of disease based on patient medical patient 

## Project Overview
This project is used to predict whether a person has a risk of heart disease or not. 
It uses a dataset that contains health information like age, cholesterol, blood pressure, and other medical values. 
I cleaned the data and converted any text values into numbers using label encoding. Then I trained a Logistic Regression model to learn from the data. 
After the model was trained, I saved it so it can be used again without retraining. 
The user can enter their health details, and the model will predict the result: either risk of heart disease or no risk.
I also saved the user’s input and the prediction result into a local SQLite database. This helps keep a record of all the predictions. 
This project is helpful for giving early warnings and supporting health decisions using data.

- **Attributes include:**

  - Chest pain type

  - Cholesterol
  - Fasting blood sugar
  - ECG results
  - Maximum heart rate
